### 13. String Partition - Recurrences

#### Word Break (139)
At index i, try every possible word. If s[i..end-1] is in dict and rest can be broken, return true.
```
solve(i):
  if i == n: return true
  for end = i+1 to n:
    if s[i..end-1] in dict AND solve(end): return true
  return false

// Answer: solve(0)
```

#### Word Break II (140)
Same structure as I, but return all valid sentences instead of true/false.
```
solve(start_index):
  if start_index == n: return [""]

  sentences = []
  for i = start_index to n-1:
    word = s[start_index..i]
    if word in dict:
      for suffix in solve(i+1):
        sentences.add(word + " " + suffix)

  return sentences

// Answer: solve(0)
```

#### Palindrome Partitioning II (132)
Same pattern as Word Break but check palindrome instead of dict, and minimize cuts.
```
solve(start_index):
  if start_index == n: return 0
  if isPalin[start_index][n-1]: return 0    // whole thing is palindrome

  minCuts = INF
  for i = start_index to n-1:
    if isPalin[start_index][i]:
      minCuts = min(minCuts, 1 + solve(i+1))

  return minCuts

// Answer: solve(0)
```

### 14. Catalan Numbers - Recurrences

#### Different Ways to Add Parentheses (241)
Split expression at each operator. Solve left and right recursively. Combine all pairs.
```
solve(expr):
  if expr is a number: return [number]

  results = []
  for each operator at position i:
    leftResults  = solve(expr[0..i-1])
    rightResults = solve(expr[i+1..end])

    for each l in leftResults:
      for each r in rightResults:
        results.add(l op r)

  return results
```

### 15. DP on Grids - Recurrences

#### Unique Paths (62)
Count paths from (0,0) to (m-1,n-1) moving only right or down.
```
solve(i, j):
  if i == 0 and j == 0: return 1   // reached start
  if i < 0 or j < 0: return 0      // out of bounds

  return solve(i-1, j) + solve(i, j-1)   // from above + from left
```

#### Unique Paths II (63)
Same as I, but obstacles block paths. If cell has obstacle, return 0.
```
solve(i, j):
  if i < 0 or j < 0: return 0          // out of bounds
  if grid[i][j] == 1: return 0          // obstacle
  if i == 0 and j == 0: return 1        // reached start

  return solve(i-1, j) + solve(i, j-1)
```

#### Minimum Path Sum (64)
Find min cost path from (0,0) to (m-1,n-1). Same structure but min instead of sum.
```
solve(i, j):
  if i < 0 or j < 0: return INT_MAX    // out of bounds (invalid path)
  if i == 0 and j == 0: return grid[0][0]  // reached start

  return grid[i][j] + min(solve(i-1, j), solve(i, j-1))
```

#### Minimum Falling Path Sum (931)
Start at any cell in last row, reach any cell in first row. 3 directions: up-left, up, up-right.
```
solve(i, j):
  if j < 0 or j >= n: return INT_MAX   // out of bounds
  if i == 0: return matrix[0][j]        // reached first row

  return matrix[i][j] + min(solve(i-1,j-1), solve(i-1,j), solve(i-1,j+1))

// Answer: min(solve(n-1, j)) for all j in 0..n-1
```

#### Triangle (120)
From (0,0), move to (i+1,j) or (i+1,j+1). Find min path sum to last row. Fill bottom-up from last row.
```
solve(i, j):
  if i == n-1: return triangle[n-1][j]   // last row = base case

  return triangle[i][j] + min(solve(i+1, j), solve(i+1, j+1))

// Answer: solve(0, 0)
```

#### Max Path Sum Triangle
Same as Triangle (120) but max instead of min. Print path by backtracking dp greedily.
```
solve(i, j):
  if i == n-1: return triangle[n-1][j]   // last row = base case

  return triangle[i][j] + max(solve(i+1, j), solve(i+1, j+1))

// Answer: solve(0, 0)
// Print path: from (0,0), at each row pick direction where dp[i+1][j+1] > dp[i+1][j]
```

#### Maximal Square (221)
dp[i][j] = side of largest square with bottom-right at (i,j). Bottleneck = smallest of 3 neighbors.
```
solve(i, j):
  if i < 0 or j < 0: return 0
  if matrix[i][j] == '0': return 0

  return 1 + min(solve(i-1, j), solve(i, j-1), solve(i-1, j-1))

// Answer: max(solve(i, j))² for all (i, j)
```

#### Number of Paths with K Coins
3D state: (row, col, coinsRemaining). Subtract current cell coins at each step.
```
solve(i, j, k):
  if i < 0 or j < 0 or k < 0: return 0
  if i == 0 and j == 0: return (k == grid[0][0]) ? 1 : 0

  return solve(i-1, j, k - grid[i][j]) + solve(i, j-1, k - grid[i][j])

// Answer: solve(m-1, n-1, K)
```

#### Collect Max Coins
3D state: (row, col, direction). Zigzag: facing right can go right or down(flip left). Facing left can go left or down(flip right).
```
solve(i, j, dir):
  if out of bounds or grid[i][j] == '#': return 0
  coins = (grid[i][j] == 'C') ? 1 : 0

  if dir == RIGHT:
    return coins + max(solve(i, j+1, RIGHT), solve(i+1, j, LEFT))
  else:
    return coins + max(solve(i, j-1, LEFT), solve(i+1, j, RIGHT))

// Answer: solve(0, 0, RIGHT)
```

#### Two Traversals Max Points
Two traversals move together row by row. State: (row, col1, col2). 9 move combos (3 for each traversal). Same cell → count points once.
```
solve(row, col1, col2):
  if col1 or col2 out of bounds: return -INF
  if row == R: return 0

  points = grid[row][col1] + (col1 != col2 ? grid[row][col2] : 0)
  return points + max over all (dc1, dc2) in {-1,0,1}x{-1,0,1}:
    solve(row+1, col1+dc1, col2+dc2)

// Answer: solve(0, 0, C-1)
```

#### Gold Mine
Start any row in column 0, move right/right-up/right-down. Fill columns right to left.
```
solve(i, j):
  if i < 0 or i >= R: return -INF
  if j == C-1: return grid[i][j]       // last column = base case

  return grid[i][j] + max(solve(i, j+1), solve(i-1, j+1), solve(i+1, j+1))

// Answer: max(solve(i, 0)) for all i in 0..R-1
```

#### Cherry Pickup I (741)
Two persons from (0,0) to (n-1,n-1) simultaneously. State: (step k, row1, row2). Columns derived: c = k - r. Same cell → count cherry once. 4 move combinations per step.
```
solve(k, r1, r2):
  c1 = k-r1, c2 = k-r2
  if out of bounds or thorn: return -INF
  if r1==n-1 && c1==n-1 && r2==n-1 && c2==n-1: return grid[r1][c1]  // both at destination

  cherries = grid[r1][c1] + (r1 != r2 ? grid[r2][c2] : 0)
  return cherries + max(
    solve(k+1, r1, r2),       // both right
    solve(k+1, r1, r2+1),     // p1 right, p2 down
    solve(k+1, r1+1, r2),     // p1 down, p2 right
    solve(k+1, r1+1, r2+1))   // both down

// Answer: max(0, solve(0, 0, 0))
```

#### Cherry Pickup II (1463)
Robot1 at (0,0), Robot2 at (0,C-1), both move down. Row is the step counter (no K trick needed). 9 move combos per step.
```
solve(row, col1, col2):
  if col1/col2 out of bounds: return -INF
  if row == R: return 0

  cherries = grid[row][col1] + (col1 != col2 ? grid[row][col2] : 0)
  return cherries + max over (dc1, dc2) in {-1,0,1}x{-1,0,1}:
    solve(row+1, col1+dc1, col2+dc2)

// Answer: solve(0, 0, C-1)
```

#### Paint House I
State: (house index, color). No two adjacent houses same color. 3 colors.
```
solve(i, color):
  if i == 0: return costs[0][color]

  return costs[i][color] + min(solve(i-1, prevColor)) for prevColor != color

// Answer: min(solve(n-1, 0), solve(n-1, 1), solve(n-1, 2))
```

#### Dungeon Game (174)
Solve backwards: dp[i][j] = min health needed entering (i,j) to survive to end. Forward fails because future potions affect how much initial HP you need.
```
solve(i, j):
  if i >= m or j >= n: return INF           // out of bounds
  if i == m-1 and j == n-1:                 // destination
    return max(1, 1 - dungeon[i][j])

  minHealthNeeded = min(solve(i+1, j), solve(i, j+1))
  return max(1, minHealthNeeded - dungeon[i][j])

// Answer: solve(0, 0)
```

### 16. DP on Trees - Recurrences

#### Diameter of Tree
At each node, compute left and right subtree heights. The path through this node = L + R edges. Return single side height to parent.
```
height(node):
  if node == null: return 0
  L = height(node->left)
  R = height(node->right)

  diameter = max(diameter, L + R)   // global update (edges in path through this node)
  return 1 + max(L, R)             // return to parent (longest single branch)
```

#### Maximum Path Sum (124)
At each node, take both branches if positive for global update, but return only one branch to parent. Use `max(0, branch)` to discard negative contributions.
```
maxGain(node):
  if node == null: return 0
  L = max(0, maxGain(node->left))
  R = max(0, maxGain(node->right))

  maxSum = max(maxSum, node->val + L + R)   // global update (both branches)
  return node->val + max(L, R)              // return to parent (one branch only)
```

#### Maximum Path Sum Leaf to Leaf
Path must start and end at leaf nodes. No `max(0, branch)` since we must reach leaves. Only update global when node has both children.
```
maxGain(node, maxSum):
  if node == null: return 0
  if node is leaf: return node->val

  L = maxGain(node->left, maxSum)
  R = maxGain(node->right, maxSum)

  if both children exist:
    maxSumViaThisNode = val + L + R
    maxSum = max(maxSum, maxSumViaThisNode)   // leaf-to-leaf through this node
    return val + max(L, R)                    // return better branch

  if only left:  return val + L
  if only right: return val + R
```

#### House Robber III (337)
At each node, return a pair `{rob, skip}`. If we rob this node, we must skip children. If we skip, take the best from each child.
```
dfs(node):
  if node == null: return {0, 0}

  {leftRob, leftSkip}   = dfs(node->left)
  {rightRob, rightSkip} = dfs(node->right)

  robThis  = node->val + leftSkip + rightSkip
  skipThis = max(leftRob, leftSkip) + max(rightRob, rightSkip)

  return {robThis, skipThis}
```

#### Binary Tree Cameras (968)
Greedy post-order. 3 states: 0=not monitored, 1=has camera, 2=monitored. Null nodes return 2. Place cameras as low as possible (on parents of leaves) to maximize coverage.
```
dfs(node):
  if node == null: return 2 (monitored)

  left  = dfs(node->left)
  right = dfs(node->right)

  if left == 0 or right == 0:   // child not monitored
    cameras++
    return 1                    // place camera here

  if left == 1 or right == 1:   // child has camera
    return 2                    // we are monitored

  return 0                      // NOT monitored, parent will handle

// After DFS: if root returns 0, add one more camera on root.
```

#### Diameter of N-ary Tree
Same as binary tree diameter but track the two tallest child heights. The diameter through a node = sum of its two tallest branches.
```
height(node):
  if node == null: return 0

  maxHeight1 = 0, maxHeight2 = 0   // two tallest children
  for each child in node->children:
    h = height(child)
    update maxHeight1, maxHeight2 with h

  diameter = max(diameter, maxHeight1 + maxHeight2)   // global update
  return 1 + maxHeight1                               // return to parent
```

### 21. State Machine DP - Recurrences

#### Stock I (121)
No recurrence needed. Single pass tracking min price.

**States:** None (greedy single pass).

#### Stock II (122)
Unlimited transactions.

**States:** `dp[n+1][2]` → `i`: 0 to n (n+1 values), `canBuy`: 0 or 1 (2 values).
```
solve(i, canBuy):
  if i == n: return 0
  if canBuy:
    buy  = -prices[i] + solve(i+1, 0)
    skip = solve(i+1, 1)
    return max(buy, skip)
  else:
    sell = prices[i] + solve(i+1, 1)
    skip = solve(i+1, 0)
    return max(sell, skip)
```

#### Stock III (123)
At most 2 transactions.

**States:** `dp[n+1][2][3]` → `i`: 0 to n (n+1), `canBuy`: 0 or 1 (2), `txLeft`: 0 to 2 (3 values).
```
solve(i, canBuy, txLeft):
  if i == n or txLeft == 0: return 0
  if canBuy:
    buy  = -prices[i] + solve(i+1, 0, txLeft)
    skip = solve(i+1, 1, txLeft)
    return max(buy, skip)
  else:
    sell = prices[i] + solve(i+1, 1, txLeft - 1)
    skip = solve(i+1, 0, txLeft)
    return max(sell, skip)
```

#### Stock IV (188)
At most K transactions. Same as III with `txLeft = k`.

**States:** `dp[n+1][2][k+1]` → `i`: 0 to n (n+1), `canBuy`: 0 or 1 (2), `txLeft`: 0 to k (k+1 values).
```
solve(i, canBuy, txLeft):
  if i == n or txLeft == 0: return 0
  if canBuy:
    buy  = -prices[i] + solve(i+1, 0, txLeft)
    skip = solve(i+1, 1, txLeft)
    return max(buy, skip)
  else:
    sell = prices[i] + solve(i+1, 1, txLeft - 1)
    skip = solve(i+1, 0, txLeft)
    return max(sell, skip)
```

#### Stock with Cooldown (309)
Sell jumps to i+2 instead of i+1.

**States:** `dp[n+2][2]` → `i`: 0 to n+1 (n+2 values, extra because sell jumps to i+2), `canBuy`: 0 or 1 (2).
```
solve(i, canBuy):
  if i >= n: return 0
  if canBuy:
    buy  = -prices[i] + solve(i+1, 0)
    skip = solve(i+1, 1)
    return max(buy, skip)
  else:
    sell = prices[i] + solve(i+2, 1)      // cooldown: skip next day
    skip = solve(i+1, 0)
    return max(sell, skip)
```

#### Stock with Transaction Fee (714)
Subtract fee on sell.

**States:** `dp[n+1][2]` → `i`: 0 to n (n+1 values), `canBuy`: 0 or 1 (2 values).
```
solve(i, canBuy):
  if i == n: return 0
  if canBuy:
    buy  = -prices[i] + solve(i+1, 0)
    skip = solve(i+1, 1)
    return max(buy, skip)
  else:
    sell = prices[i] - fee + solve(i+1, 1)
    skip = solve(i+1, 0)
    return max(sell, skip)
```
